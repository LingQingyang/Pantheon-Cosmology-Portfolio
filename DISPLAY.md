# Display scope and provenance

This portfolio presents saved coursework figures and high-level learning experience by Qingyang Ling. The original solution files are retained in a separate private archive.

The public selection includes original visual outputs and newly written overview pages. It excludes submitted implementations, mathematical derivations, original assignment and answer PDFs, detailed result tables, numerical data arrays, course-supplied datasets, and model checkpoints. It is created from a fresh Git history containing only the selected display files.

Figure pixels remain unchanged. Some plots therefore contain their original numerical axes or annotations; no numerical result table or prose transcription of those values is included. Generic model descriptions and qualitative captions do not provide solution code or a derivation.

These are saved coursework outputs presented as a learning portfolio. Training and inference were not rerun while organizing this gallery.
